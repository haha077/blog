Windows局域网共享设置

①右键需要共享的盘或者文件夹 → 属性 → 共享 → 高级共享。

勾选“共享此文件夹”。

进入“权限”，给用于访问的账户授予读取权限；如果需要写入则授予相应权限。

②目标pc尝试访问

\\192.168.X.X

此时通常会提示密码或者权限不足拒绝

③源电脑上操作：

  1. 打开高级共享设置

控制面板 → 网络和 Internet → 网络和共享中心 → 更改高级共享设置。

  1. 关闭密码保护共享

展开“所有网络”，找到“密码保护的共享”，选择“关闭密码保护共享”，然后保存更改。

3.打开“控制面板 → 网络和共享中心 → 更改高级共享设置”。

4.在当前网络配置文件中开启：

  • 网络发现
  • 文件和打印机共享
  1. 在“所有网络”中，可以暂时关闭“密码保护的共享”进行测试。

④在源电脑设置共享权限

假设 LOL 文件夹在源电脑的 H:\LOLBackup\lol。

  1. 右键 H:\LOLBackup\lol → 属性 → 共享 → 高级共享。
  2. 勾选“共享此文件夹”，共享名填写 LOL。
  3. 点击“权限”，添加 Everyone，允许“读取”。
  4. 再进入“安全”选项卡，点击“编辑” → “添加”，输入 Everyone → 检查名称 → 确定。
  5. 在 NTFS 权限中，允许 Everyone 读取和执行、列出文件夹内容、读取，然后应用。

注意：共享权限和“安全”选项卡的 NTFS 权限是两套独立权限，两边都必须允许读取。只给共享权限还不够。

⑤重复执行②此时应该可以正常访问打开
